# Walkman 🎧

Walkman is a responsive music genre hub built using Next.js. It allows users to explore various music genres, play songs, and interact with modern playback controls.

## Features

- Genre-based song browsing
- Audio playback with play/pause, shuffle, repeat
- Download option to listen offline
- Responsive UI with dynamic media
- Cleanly structured and optimized using latest Next.js app directory features

## Installation

Clone the repository and install dependencies:

```
git clone https://github.com/TamizhSK/Walkman.git
cd Walkman
npm install
````

## Development

To start the development server:

```
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## Build

To create an optimized production build:

```
npm run build
```

To preview the production build locally:

```
npm run start
```
